


1.為minecraft:stick新增自訂義附魔
黑洞(BlackHole)
可以迅速吸住100格內的任何生物(不包含玩家)(持續5s, 結束後變回普通方塊)
尖刺(Thorns)
碰到該方塊的任何生物都會每秒扣3滴血
挖方塊時也會扣血
爆炸(Explosion)
開始閃爍, 3秒後爆炸
沉重(Heavy)
方塊會一直往下墜落破壞任何方塊(包含基岩), 掉落到y=-500時刪除
感染(Infection)
會一直無限蔓延附近方塊至100格
(假設我放的是鑽石方塊 就所有任何方塊都變鑽石方塊)
附近生物部會被固定無法動(NoAI:1b)
附近生物都命名被感染的生物
彈跳(Bounce)
該方塊變成有像史萊姆的彈跳效果
破碎(Shatter)
那個方塊被踩到會消失+掉落物品(玻璃破碎音效)
左鍵點擊也會像玻璃一樣被秒挖(包含基岩)
無限(Infinity)
標記方塊後破壞 會獲得帶有無限附魔的對應方塊
該方塊可以無限放置
也可以無限丟棄(丟出時會補充一樣的)
加速(Speed)
該方塊會有加速效果,且站在該類型方塊上速度會越來越快
衝能(Charge)
(站在該方塊上)會獲得回復狀態(包含血量、飢餓與裝備耐久)
新增這些自訂義附魔
並為他們創建enchanted book(可以放上鐵砧與stick合成)
放入itemgroup中
2.當玩家拿著含有自訂義附魔的stick左鍵點擊方塊
該方塊出現附魔的特效, 以標記方式繼承stick的附魔效果來判定(可同時存在)
